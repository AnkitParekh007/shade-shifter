# Accessibility

Material controls use at least 48dp targets. The UI supports system text scaling, light/dark themes, semantic labels, screen readers, visible focus, and non-color status text. The preview has an image description and every swatch has a spoken color value. Motion is brief and nonessential; system reduced-motion settings should disable future auto-rotation/effects.

Test at 200% text, TalkBack, VoiceOver, increased contrast, dark mode, and landscape. Safety messages must never rely on color alone.
